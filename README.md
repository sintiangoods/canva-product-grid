# Canva 商品 12 宮格技能

供 Codex 重複製作商品型錄的技能，延續現有 Canva 版型或附帶參考圖。

## 排版規則

- 直式 A4、3 欄 × 4 列，共 12 格。
- 品名使用饅頭黑體，型號及售價採大字粗體。
- 商品圖左下加入圓角顏色標籤。
- 保留圖片比例、品名與型號配對；未確認的價格不填入。
- 新增頁面時保留原有型錄內容。

![12 宮格參考](assets/reference-grid.png)

## 安裝

將此儲存庫下載後，把包含 `SKILL.md`、`agents/` 和 `assets/` 的資料夾放到個人的 Codex `skills/canva-product-grid` 目錄。

## 使用

```text
使用 $canva-product-grid，依照這個版型與我提供的圖片資料夾，製作新的商品12宮格頁面。
```

提供圖片資料夾或可存取來源、要使用的品項、Canva 設計連結，以及價格資料（如需顯示）。

Canva 編輯需要有效的帳戶連線；字型也需在目標環境可用。本儲存庫不包含字型檔。商品預覽僅供版型參考。
